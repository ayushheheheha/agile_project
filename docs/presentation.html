The Problem Space

The Technical Hiring Bottleneck

Why traditional manual screening and legacy ATS systems fail hiring teams and candidates.

⏳ High Volume & Latency

Engineering job openings average 250+ applications. Recruiters spend over 75% of their working hours manually scanning resumes, creating weeks of candidate backlog.

🎯 Keyword Bias & Inaccuracy

Traditional ATS filters use rigid string search. Qualified engineers are rejected if their resume lists "Docker & Containerization" instead of the exact phrase "Docker container orchestration".

🕳️ Candidate Black Hole

Candidates experience zero transparency: no alignment score, no constructive skill feedback, and status updates that take months or never arrive.

The Product Solution

Dual-Role Workflow & Objective Scoring

A streamlined, professional internal tool that connects recruiters and candidates seamlessly.

👔 Recruiter Experience

  • Post technical roles with strict required skill requirements.
  • Dashboard automatically ranks applicants by AI score (0–100).
  • Instant breakdown of matched vs. missing skills for each candidate.
  • One-click status transitions: Pending Reviewed Hired Rejected.

💼 Candidate Experience

  • Browse active positions with real-time recruiter information.
  • Submit applications with standard PDF resume uploads.
  • Real-time Gemini AI scoring and objective match summaries.
  • Application tracking portal showing application status and score cards.

🔒 Security & Isolation

Supabase Row Level Security (RLS) ensures candidates can only read their own applications, while recruiters can only view applicants for jobs they personally authored.

⚡ Zero Disk Footprint

Multer uses in-memory buffer storage. Resumes are parsed in RAM and streamed directly to Supabase Storage without writing temporary files to server disks.

Container Orchestration

Docker Compose & Multi-Stage Builds

Production-grade image optimization and zero-configuration local orchestration.

🐳 Multi-Stage Frontend Build

Stage 1 (Builder): node:20-alpine installs dev dependencies and compiles Vite bundle.

Stage 2 (Runner): nginx:alpine copies only the compiled /dist folder. Discards Node, npm, and dev tools.

✔ Result: Tiny production image (~25 MB) with zero runtime Node vulnerability surface.

🌐 Nginx Reverse Proxy & Health Checks

  • CORS Elimination: Browser communicates only with port 80. Nginx proxies /api/* to http://backend:4000 internally.
  • Health Checks: Backend runs automated wget http://localhost:4000/health every 30s.
  • Startup Dependency: depends_on: condition: service_healthy ensures correct startup sequence.
AI Engineering & Resiliency

Fault-Tolerant AI Scoring Pipeline

Graceful degradation guarantees that candidate applications are never blocked by AI failures.

Tier 1

Code Fence Cleaner

Strips ```json ... ``` wrappers commonly returned by LLMs to ensure reliable JSON.parse() execution.

Tier 2

Rate-Limit Retry

Catches HTTP 429 quota exhaustion on free-tier Gemini API, waits 5 seconds, and automatically retries once.

Tier 3

Local Scorer Fallback

Calculates skill overlap (matched/total * 100). Returns the identical output shape so the UI never crashes.

Tested & Verified: All fallback branches (malformed JSON, rate limit retry, missing API key, score clamping) are verified by our 14 Jest unit tests.
